From full-stack beginnings to senior backend work — the throughline is the same: ship features end-to-end, keep production healthy, and make systems easier to maintain.

I’m a Go backend engineer based in Central Java, currently a Senior Back End Engineer at Komerce in Purbalingga. I build services for a product that integrates the WhatsApp Business Platform and Meta Marketing API, helping clients run WhatsApp marketing and messaging workflows.

The hard part isn’t just calling an API — it’s what happens when that API times out, rate-limits, or fails halfway through. I design for that: fault-tolerant, resumable services where interrupted actions continue safely, backed by RabbitMQ for asynchronous jobs and Redis for caching.

Before Komerce, I cut response times by up to 80% on high-traffic mobile endpoints at PT Pitjarus Teknologi and built MySQL → ClickHouse ETL pipelines for analytics. Earlier, at PT Puskomedia Indonesia Kreatif, I built full-stack web and Android products and led a PHP 5 → PHP 7 upgrade of the main product.

What I focus on

  • Refactoring core services for maintainability
